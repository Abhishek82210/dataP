# 📊 Real-Time Data Visualization Platform

A simple yet powerful client-side web application that allows users to upload CSV files and visualize the data instantly using beautiful, interactive charts. Built with **HTML**, **CSS**, and **JavaScript** — no backend required!

---

## 🚀 Features

- 📂 Upload CSV files and parse data
- 📊 Visualize data using various chart types:
  - Bar
  - Pie
  - Doughnut
  - Radar
- 🌙 Toggle Dark/Light Mode
- 🖼 Download chart as PNG (with white background)
- 🧾 View CSV data in a structured table
- 💾 Save the last uploaded data and chart type in **Local Storage**
- ⚡ Fully responsive and runs completely in the browser (no backend needed)

---

``

Upload a .csv file in the format:
```

```
